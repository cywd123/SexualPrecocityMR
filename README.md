## 二、AMH（MIS）—— 唯一有实质内容的信号

### 2.1 全部显著记录（deCODE 4907 面板）

| 表型 | 阈值 | 工具变量 | b | OR | p |
|---|---|---|---|---|---|
| **PREPUB** | 5e-8 | 10 | **−1.046** | 0.35 | **0.0163** |
| PREPUB | 5e-7 | 11 | −0.973 | 0.38 | 0.0233 |
| PREPUB | 5e-6 | 15 | −0.812 | 0.44 | 0.0490 |
| **CPP** | 5e-8 | 10 | **+0.893** | 2.44 | **0.0145** |
| CPP | 5e-7 | 11 | +0.911 | 2.49 | 0.0114 |
| CPP | 5e-6 | 15 | +0.879 | 2.41 | 0.0113 |

**特征**：
- 每个表型内部，三个阈值方向完全一致，p 值随工具变量增加而稳定
- 每个表型内部，IVW / MR-Egger / Weighted median 三法方向也一致
- 工具变量很强：平均 F=256，最小 F=30，总 F=2560

### 2.2 但跨表型方向相反

```
PREPUB: −1.046 ± 0.436  (OR 0.35)
CPP    : +0.893 ± 0.365  (OR 2.44)
差值   : +1.939 ± 0.568,  z = 3.41,  p = 0.0006
```

**异质性显著（p=0.0006）。** 这不是"一个显著一个不显著"，是"两个都显著但方向完全相反"——最难处理的一种情况。

### 2.3 其他层面：全空

| 层面 | 结果 |
|---|---|
| SMR 下丘脑 / 垂体 / 全血 | 0.659 / 0.659 / 0.659（HEIDI 0.64–0.80 通过） |
| TWAS 下丘脑 / 垂体 / 全血 | 0.438 / 0.314 / 0.615 |
| MAGMA PREPUB / CPP | Z=−0.25 (p=0.60) / Z=−0.36 (p=0.64) |
| eQTL MR PREPUB / CPP | p=0.580 / p=0.329 |

**表达层面完全没有支持。**

## 三、INHBB —— 四个显著结果，四个方向

| 层面 | PREPUB | CPP |
|---|---|---|
| **MAGMA**（SNP 层面） | **Z=+2.25，p=0.0123**（正） | **Z=−2.12，p=0.0171**（负） |
| **eQTL MR**（21 SNP） | **b=−0.670，OR 0.51，p=0.0294**（负） | b=+0.213，p=0.411（正但不显著） |
| **pQTL MR**（deCODE，40 SNP） | b=+0.026，OR 1.03，p=0.915（正但不显著） | **b=+0.436，OR 1.55，p=0.0397**（正） |

**这张表的问题很明显**：
- MAGMA 说 PREPUB 正、CPP 负
- eQTL MR 说 PREPUB 负
- pQTL MR 说 CPP 正

**同一个基因，四个显著结果，方向覆盖了正负两种、层面覆盖了三种，没有任何两条能互相印证。**

这不是"证据多元"，这是"每个层面各自在抓噪声"。

## 五、INHBA —— 唯一显著的是适配体假象

### 5.1 Sun_BB 面板：同一蛋白，两个适配体，方向相反

| 适配体 | 蛋白名 | PREPUB | CPP |
|---|---|---|---|
| **prot-a-1555** | Inhibin beta A:beta B heterodimer | **+0.765 (OR 2.15), p=0.0041** | +0.128, p=0.689 |
| **prot-a-1554** | 同上 | **−0.243 (OR 0.78), p=0.321** | +0.205, p=0.325 |

**两个适配体测的是同一个蛋白（即激活素 AB），却给出相反的效应方向。** 其中 prot-a-1555 的 p=0.0041 是全通路最"漂亮"的 p 值——但被 prot-a-1554 直接否定。这是 SomaScan 适配体交叉反应的典型表现。

## 八、一句话回答

**显著的结果只有两类：AMH 和 INHBB。**

- **AMH**：6 条显著记录，工具变量强、表型内高度一致，但**跨表型方向完全翻转（异质性 p=0.0006）**——这是唯一值得深挖的信号，也是最难解释的矛盾
- **INHBB**：4 条显著记录，但 MAGMA、eQTL MR、pQTL MR 三个层面**方向互相矛盾**，无法整合
- **INHA**：零条。因为它根本不在任何蛋白面板里，eQTL 层面也没有模型——"抑制素"这条线断在这里
- **INHBA**：唯一显著的结果是适配体假象

**如果只挑一条写进文章，只能是 AMH，但必须同时报告那个方向翻转，不能藏。**
